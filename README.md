# Temperature Converter

A Java console-based program that converts temperature between Celsius, Fahrenheit, and Kelvin.

## Features
- User input support
- Converts between all three units
- Clean console output

## Author
Keerthan 

## Sample Test Cases
1. Input: 25 C → Output: 77.00 F, 298.15 K  
2. Input: 350 K → Output: 76.85 C, 170.33 F  
3. Input: 500 F → Output: 260.00 C, 533.15 K
